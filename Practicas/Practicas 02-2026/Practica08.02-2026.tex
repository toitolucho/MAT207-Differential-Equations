\subsection*{A) Planteamiento del Wronskiano y Formulación de Integrales}
Determina $y_h(x)$, calcula el Wronskiano $W(x)$ y plantea las integrales para $u_1(x)$ y $u_2(x)$ sin evaluarlas.

\begin{multicols}{2}
\begin{enumerate}[itemsep=0.15cm]
    \item $y'' + y = \tan(x)$
    \item $y'' + 4y = \sec(2x)$
    \item $y'' - 2y' + y = \dfrac{e^x}{x^2 + 1}$
    \item $y'' - 3y' + 2y = \dfrac{1}{1 + e^{-x}}$
    \item $x^2 y'' + x y' - 4y = x^3 \ln(x), \quad y_1 = x^2, \; y_2 = x^{-2}$
\end{enumerate}
\end{multicols}

\subsection*{B) Resolución Completa por Variación de Parámetros}
Encuentra la solución general $y(x) = y_h(x) + y_p(x)$ de cada ecuación utilizando el método de variación de parámetros.

\begin{multicols}{2}
\begin{enumerate}[itemsep=0.15cm]
    \item $y'' + y = \tan(x)$
    \item $y'' + y = \sec(x)$
    \item $y'' + 4y = \sec(2x)$
    \item $y'' - 2y' + y = \dfrac{e^x}{x}, \quad x > 0$
    \item $y'' - y = \dfrac{2}{1 + e^x}$
    \item $y'' + 3y' + 2y = \dfrac{1}{1 + e^x}$
    \item $y'' + y = \csc(x), \quad 0 < x < \pi$
    \item $y'' - 4y' + 4y = \dfrac{e^{2x}}{x^2}, \quad x > 0$
\end{enumerate}
\end{multicols}

\subsection*{C) Coeficientes Variables (Cauchy-Euler) y Orden Superior}
Resuelve las siguientes ecuaciones diferenciales utilizando el método de variación de parámetros.

\begin{multicols}{2}
\begin{enumerate}[itemsep=0.15cm]
    \item $x^2 y'' - 2x y' + 2y = x^4 e^x, \quad y_1 = x, \; y_2 = x^2$
    \item $x^2 y'' + x y' - y = \dfrac{1}{x+1}, \quad y_1 = x, \; y_2 = x^{-1}$
    \item $y''' + y' = \tan(x), \quad -\dfrac{\pi}{2} < x < \dfrac{\pi}{2}$
    \item $x^2 y'' - 3x y' + 3y = 2x^4 \sin(x), \quad y_1 = x, \; y_2 = x^3$
\end{enumerate}
\end{multicols}
